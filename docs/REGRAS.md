# Regras Omega

1. Nenhuma ação de sistema sem token do desenvolvedor.
2. Cloud LLM desligada por padrão.
3. Autoaperfeiçoamento nunca aplica em produção sem backup + confirmação.
4. Shell e filesystem só na allowlist.
5. Idioma padrão: pt-BR.
6. Conhecimento importante persiste em banco + vetor + arquivo.
